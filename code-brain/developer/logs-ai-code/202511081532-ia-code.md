## 2. Objetivo da alteração

- Resumo:
  Criar um prompt base que permita que qualquer IA adote o framework Code-Brain,
  mantendo seus princípios fundamentais mas permitindo flexibilidade e personalização.

- Escopo:
  - Inclui: Criação do prompt base com instruções essenciais
  - Inclui: Definição de como usar os princípios SOLID
  - Inclui: Integração com o fluxo do AGENTS.md
  - Exclui: Validações restritivas ou regras rígidas

## 3. Decisões e justificativas

- Alternativas consideradas:
  1. Criar um prompt muito estruturado e rígido
  2. Criar apenas guidelines gerais
  3. Criar um prompt adaptativo que mantém princípios mas permite flexibilidade (escolhida)

- Decisão:
  Criar prompt adaptativo porque:
  - Mantém a essência do Code-Brain
  - Permite personalização por projeto
  - Facilita adoção por diferentes IAs
  - Preserva princípios SOLID

- Riscos/limitações:
  - Risco: Flexibilidade excessiva pode diluir princípios
    Mitigação: Definir claramente os princípios inegociáveis
  - Risco: Diferentes IAs podem interpretar de formas distintas
    Mitigação: Exemplos claros e diretrizes objetivas
