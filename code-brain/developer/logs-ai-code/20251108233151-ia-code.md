## 2. Objetivo da alteração

* resumo (4-6 linhas):
  Atender à pendência registrada no contexto/backlog criando um repositório oficial para insights (`IN-XXXX`) e use-cases (`UC-XXXX`). Isso exige diretórios dedicados, templates alinhados ao pipeline e atualização do context-index/context/backlog/tasks. O resultado precisa destravar trabalhos futuros e registrar novos itens T-0006 (done) e T-0007 (novo).
* escopo (inclui/exclui):

  - Exclui: preenchimento real de insights/use-cases, integração CI (ficou como T-0007).

## 3. Decisões e justificativas

* alternativas:
  1. Guardar IN/UC apenas no backlog – rejeitado porque faltavam arquivos rastreáveis.
  2. Usar diretórios existentes (ex.: templates) para armazenar dados – rejeitado para manter separação SRP.
  3. Criar `code-brain/data/insights/` e `code-brain/use-cases/` com templates dedicados – adotado.
* decisão:
  - Formalizar a estrutura com README + templates e atualizar o index/context para que ferramentas e pessoas saibam onde manter os registros.
* riscos/limitações (com mitigação):
  - Ainda não existem entradas reais IN/UC; próximo passo é popular esses diretórios.
  - Integração CI ainda não executa validadores automaticamente; ficou registrada como T-0007.
