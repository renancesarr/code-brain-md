## 2. Objetivo da alteração

* resumo (4-6 linhas):
  Concluir a T-0007 integrando o script `code-brain/scripts/validate-docs.sh` ao pipeline CI/preflight documentado, garantindo que GitHub Actions, GitLab CI e Jenkins executem a validação antes do `preflight.sh`. Atualizar contexto/backlog/tasks para refletir a automação e registrar a conclusão. A ação reforça o estágio TEST automático do AGENTS.
* escopo (inclui/exclui):
  - Inclui: atualização da guideline `preflight-cicd.md`, sincronização de `context.yaml`, `backlog`, `tasks.yaml`, execução do script de validação e criação desta nota.
  - Exclui: implementação real do pipeline em repositórios externos, coleta de métricas pós-execução.

## 3. Decisões e justificativas

* alternativas:
  1. Abrir um novo script CI separado – rejeitado para evitar divergência; guidelines já centralizam.
  2. Modificar `preflight.sh` para chamar `validate-docs.sh` diretamente – descartado para manter responsabilidade separada.
  3. Inserir o passo `code-brain/scripts/validate-docs.sh` em cada exemplo CI do `preflight-cicd.md` – adotado.
* decisão:
  - Manter preflight focado nas checagens Git, mas documentar claramente que `validate-docs.sh` roda antes de `preflight.sh check-all` em todas as pipelines de referência.
* riscos/limitações (com mitigação):
  - Dependência de `python3`/`yamllint` no CI: guideline já indica instalação prévia (npm ci + script). Equipes devem garantir ambiente adequado.
  - Falta de monitoramento automático: backlog passa a cobrar relatórios futuros.
