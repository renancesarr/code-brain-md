## 2. Objetivo da alteração
* resumo (4-6 linhas):
  Tornar a guideline `preflight-cicd.md` mais objetiva, mantendo somente os exemplos de pipelines (GitHub Actions, GitLab CI, Jenkins) e referenciando os documentos especializados para variáveis, flags e scripts auxiliares. Antes havia blocos inteiros duplicados com o material presente nos templates de preflight.
* escopo (inclui/exclui):
  - Inclui: remoção das seções “Configurações Comuns” e “Scripts de Suporte”, adição de uma nota de referência.
  - Exclui: alterações em outros arquivos ou nos templates principais.

## 3. Decisões e justificativas
* alternativas:
  1. Manter o conteúdo duplicado – rejeitado por dificultar manutenção.
  2. Consolidar apenas parte das seções – descartado, pois a referência já existe em `preflight-special-templates`.
  3. Remover blocos redundantes e apontar para os templates oficiais – adotado.
* decisão: Documentar apenas os trechos exclusivos desta guideline (exemplos de CI) e referenciar os demais recursos.
* riscos/limitações: Necessidade de consultar outro arquivo para variáveis/flags; mitigação: adicionar links/lista de referências.
