# how to create a plan write code

## Analysis phase

  1. Examines your existing codebase and patterns
  2. Reviews related files and dependencies
  3. Studies your AGENTS.md conventions
  4. Gathers context from external sources

## Planning phase

  1. Develops comprehensive implementation strategy
  2. Identifies all files that need changes
  3. Plans sequence of modifications
  4. Considers testing and verification steps

## Safety guarantees

  1. Cannot edit files during analysis
  2. Cannot run commands that modify anything
  3. Cannot create, delete, or move files
  4. All exploration is read-only until you approve
